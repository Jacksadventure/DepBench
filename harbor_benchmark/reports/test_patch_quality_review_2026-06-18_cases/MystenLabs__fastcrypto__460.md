## 2. What is the breaking change?
The arkworks 0.3 -> 0.4 ecosystem rename: traits `AffineCurve`/`ProjectiveCurve` -> `AffineRepr`/`CurveGroup`, `PairingEngine` -> `Pairing` (`Fr` -> `ScalarField`); methods `prime_subgroup_generator()` -> `generator()`, `into_repr()`/`from_repr()` -> `into_bigint()`/`from_bigint()`, `into_projective()` -> `G1Projective::from()`, `miller_loop` -> `multi_miller_loop`, `get_point_from_x` -> `get_point_from_x_unchecked`; `BlsG1Affine::new(x,y,infinity)` (3-arg) -> 2-arg / `zero()`; serialization `serialize`/`deserialize` -> `serialize_compressed`/`deserialize_compressed`, `serialized_size()` -> `serialized_size(Compress::Yes)`; `FromBytes::read` -> `deserialize_compressed`; scalar mul `.mul(s.into_repr())` -> `.mul(s)`; `ark_std::test_rng()` -> `thread_rng()`; Groth16 free functions -> `Groth16::<E>::*` associated methods.
