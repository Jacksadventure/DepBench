## 2. What is the breaking change?
There is no runtime/behavioral breakage. The dependabot PR bumps the dev-tool `prettier` 2.0.5 -> 2.1.1; prettier 2.1 changed several formatting rules (single-arg arrow parens `(x) =>`, spaces inside object literals `{ s: 44 }`, narrower print-width line-wrapping for `assert.equal(...)`/`.split('_')`/ternary chains). The only "failure" the PR addresses is that the repo's existing source and test files no longer pass `prettier --check` under 2.1.1, so a human re-ran prettier across the codebase and committed the reformatting.
