# DepBench brand assets

| Asset | Use |
|---|---|
| `depbench-logo.svg` | Primary horizontal logo on light backgrounds |
| `depbench-logo-dark.svg` | Horizontal logo on dark backgrounds |
| `depbench-mark.svg` | Square icon, avatar, or favicon source |
| `depbench-mark-512.png` | Raster icon for platforms that do not accept SVG |
| `benchmark-flow.svg` | Benchmark pipeline diagram on light backgrounds |
| `benchmark-flow-dark.svg` | Benchmark pipeline diagram on dark backgrounds |
| `benchmark-flow-mobile.svg` | Vertical benchmark pipeline for narrow light-background viewports |
| `benchmark-flow-mobile-dark.svg` | Vertical benchmark pipeline for narrow dark-background viewports |

## Palette

| Name | Hex | Role |
|---|---|---|
| Ink | `#172033` | Primary structure and light-background wordmark |
| Verify | `#36CFC0` | Upgrade path and successful verification |
| Dependency | `#F6C85F` | Source dependency node |
| Repair | `#FF6B5E` | Changed dependency or repair node |
| Slate | `#8390A5` | Secondary dependency edge and baseline |

Keep clear space around the mark equal to at least one node width. Do not
recolor individual nodes or place the logo on visually noisy backgrounds.
