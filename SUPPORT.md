# Support

DepBench is provided as a research benchmark and is not covered by a Microsoft
commercial support contract.

Use GitHub Issues for reproducible problems with the published benchmark,
release helpers, metadata, or documentation. Include the Git commit, pinned
Hugging Face revision, task name, command, and relevant non-sensitive output.

Do not include credentials, private endpoints, personal data, or unpublished
repository content in an issue. Report security vulnerabilities privately as
described in [SECURITY.md](SECURITY.md).
